# Convergence

Manuscrit d’essai (papier → livre possible) par Micka.

## Sujet
Pensées, débats et positions sur :
- la **convergence instrumentale**
- la **valeur du travail**
- une **civilisation future** avec l’intelligence artificielle
- la couche **psychologique** (sens, dignité, peur, désir, reconnaissance)

## Forme
Pas un paper académique figé d’abord : un **cahier de bord intellectuel** qui se durcit en chapitres.

| Dossier | Rôle |
|---------|------|
| `manuscrit/` | Chapitres en cours |
| `notes/` | Fragments, citations, intuitions brutes |
| `livre/` | Plan + première version exposée (chapitres I–VII) |
| `manuscrit/05-debats/` | Objections ↔ réponses |
| `manuscrit/99-brut/` | Dump de pensées sans filtre |

## Comment travailler
1. Tu parles / tu dumps une idée
2. On la range dans le bon dossier
3. On la confronte (débat)
4. On la réécrit en prose de chapitre
