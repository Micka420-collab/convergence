## Package Stratège — A∪B∪C (verrou N0 : tension only) + R1–R5 + horizon 0–5 ans

> **N0 :** A, B et C restent **juxtaposés**. Pas de synthèse « A+B+C = régime final ».

### A — Horloge duale
**Hypothèse :** deux cadences coexistent — temps machine (décision, déploiement) et temps politique / corps (délibération, deuil, veto). Sans horloge duale, le politique est absorbé par le tick. **[fiction prospective]**  
**Invalidation si :** une seule cadence gouverne de fait (proxy unique de latence) ; ou le « temps lent » n’a aucun pouvoir de blocage.  
**Alternative / abstention :** rester en réforme KPI classique ; ou geler toute accélération jusqu’à institution lente (Collège du Siècle) — abstention sourcée si aucune cadence n’est révocable.

### B — Seuil de doute
**Hypothèse :** sous un seuil de doute moral / épistémique, fail-closed (blocage) plutôt que déploiement. Lien N0 / fiche 04. **[fiction prospective]**  
**Invalidation si :** le seuil n’est pas public, révocable, ou mesurable en natures de claim ; ou il devient veto permanent d’une caste.  
**Alternative / abstention :** seuil consultatif seulement (sans blocage) ; abstention de déploiement AGI-patient jusqu’à Chambre Veto formée **[trou composition]**.

### C — Registre vivant
**Hypothèse :** registre public des proxies, custody, dossiers TTL et invalidations — vivant (révisé), pas archive morte. **[fiction prospective]**  
**Invalidation si :** le registre n’est pas auditable par tiers ; ou les entrées n’expirent pas (TTL = 0 permanent) ; ou écriture réservée aux opérateurs seuls.  
**Alternative / abstention :** journal chaîné minimal (Risque) sans « registre civilisationnel » ; abstention si ouverture crée surface d’attaque dox / capture.

## Package Charte — formule obligatoire

Toute proposition de mise en place dans ce chapitre (et les packages ci-dessous) doit pouvoir se lire :

> **Hypothèse** *(ce qu’on tente)* **;**  
> **invalidation si** *(critère public qui tue l’hypothèse)* **;**  
> **alternative / abstention** *(quoi faire alors, y compris ne rien déployer)*.

**Hypothèse méta :** la formule elle-même réduit le théâtre d’alignement.  
**Invalidation si :** les « invalidation si » sont flous, secrets, ou jamais testés.  
**Alternative / abstention :** refuser le déploiement ; ou exiger un débat essaim avant toute prose « comment faire ».

## Package Risque — phases 0–4, gardes fail-closed

**Hypothèse :** une montée en charge en 5 phases (0→4), chaque transition bloquée si garde rouge. **[fiction prospective]**

| Phase | Garde fail-closed (ex.) |
|-------|-------------------------|
| 0 | Pas d’écriture irréversible hors journal d’essai |
| 1 | Shadow only — aucune action externe sans double confirmation humaine |
| 2 | Dual-gate — les deux tracks doivent signer ; un seul = blocage |
| 3 | Cutover îlot — rollback documenté obligatoire avant extension |
| 4 | Extension multi-îlots — veto Chambre ou abstention si doute moral |

**Invalidation si :** une phase saute sans preuve datée ; ou le fail-closed est contourné par « urgence » non journalisée ; ou le veto humain est capturable sans révocation.  
**Alternative / abstention :** rester en phase 1 (shadow) indéfiniment ; geler ; ou revenir à phase précédente (runbook).

**Tension ouverte :** fail-closed peut protéger un status quo injuste — **[trou]** critère de *réouverture juste* sans ouvrir la capture.

## Package Ops — shadow → dual-gate → cutover îlot

**Hypothèse :** même logique que CI/CD civil : d’abord *shadow* (système nouveau observe, n’agit pas), puis *dual-gate* (ancien + nouveau doivent accorder), puis *cutover îlot* (un territoire / domaine bascule, réversible). **[fiction prospective]**  
**Invalidation si :** cutover sans shadow préalable ; dual-gate cosmétique (un gate fantôme) ; îlot non isolable (spillover).  
**Alternative / abstention :** rester en shadow ; ou dual-gate permanent sans cutover ; abstention d’îlot si pas de rollback testé.

Lien Stratège phases 1–3 et Risque 1–3 — **juxtaposition**, pas fusion obligatoire.

## Package Research — Dual-track custody, 3 étapes

**Hypothèse :** custody en double voie (humain / système), révocable, auditable. **[fiction prospective]**

1. **Cartographier** qui détient quoi (identité, données, décision, corps-contrat).  
2. **Instancier** dual-track sur un domaine pilote (école, soin, ou justice — non choisi ici).  
3. **Invalider** le track qui cesse d’être auditable ou révocable — bascule ou abstention.

**Invalidation si :** un track devient irrévocable ; audit impossible aux concernés ; ou « dual » = théâtre (un track fantôme).  
**Alternative / abstention :** mono-track humain explicite ; ou gel du domaine ; abstention d’étendre hors pilote.
