# Chapitre 12 — Le corps-contrat

Le corps, dans cette fiction, n’est plus seulement biologie. Il devient **contrat de maintenance** : runbooks, modes dégradés, gates qui ferment si la preuve manque, dépendance circulaire quand le soignant est aussi le système à réparer.

**[fiction prospective]** La panne n’est pas une métaphore. C’est une scène : un voisin s’immobilise ; une prothèse refuse l’ordre ; une mise à jour exige un consentement qu’on n’a plus le temps de lire. L’annexe technique existe ailleurs dans le manuscrit ; ici, le livre garde le ton humain : qui a le droit d’ouvrir le corps-contrat, qui a le droit de dire non, qui paie quand la maintenance est une violence douce.

Le *robohumain comme voisin reste un trou de définition. Tant que Micka n’a pas fermé le mot, nous le laissons poreux — assez précis pour faire scène, assez ouvert pour ne pas inventer une espèce.
